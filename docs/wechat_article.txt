📹 CodecScope：浏览器里的视频码流分析神器

无需安装，拖入文件即可分析 H.264/H.265/H.266 码流 + HEIC 图片


🔍 为什么需要这个工具？

做视频编码的朋友都知道，分析码流是日常刚需：

✅ 看看 SPS/PPS 参数对不对
✅ 检查 slice 分割是否合理
✅ 确认 GOP 结构和帧类型分布
✅ 分析 NAL 单元的排列顺序

传统方案要么用命令行工具（如 ffprobe），要么用专业软件（如 Elecard），学习成本高、部署麻烦。

现在有了更简单的选择——CodecScope，一个完全在浏览器里运行的分析工具。


🎯 支持哪些标准？

▪️ H.264 (AVC) — 最普及的视频编码
▪️ H.265 (HEVC) — 4K/8K 主力编码
▪️ H.266 (VVC) — 下一代标准
▪️ HEIC/HEIF — iPhone 照片格式

码流类型自动识别，无需手动选择。


💡 核心功能

【1】NAL 单元列表
虚拟滚动，流畅处理数万条 NAL
显示偏移、长度、类型、帧号、可读信息
支持 H.264/H.265/H.266 全部 NAL 类型

【2】语法元素树
点击任一 NAL，逐位解析完整语法
SPS/PPS/VPS/Slice Header 等全覆盖
数值越界自动高亮警告

【3】帧结构时间轴
可视化 I/P/B slice 分布
GOP 结构一目了然
支持缩放、逐帧步进

【4】视频播放
基于 WebCodecs 的帧级预览
支持解码顺序 / 显示顺序切换
正确处理 B 帧重排

【5】MediaInfo 面板
树状展示完整容器信息
格式、时长、码率、编码日期
音频采样率/声道/位深

【6】HEIC 图片分析
解析 iPhone 拍摄的 HEIC 照片
显示 grid tile 结构
libheif WASM 解码预览


🚀 技术亮点

纯前端实现
C++ 解析核心通过 Emscripten 编译为 WebAssembly
前端原生 HTML/CSS/JavaScript，无框架依赖
零后端，浏览器打开即用

自动解封装
直接拖入 MP4/MOV 文件，自动解析：
▪️ hvcC/avcC 配置提取
▪️ 轨道信息识别
▪️ 帧数据分离

移动端适配
▪️ 窄屏自动切换堆叠布局
▪️ 底部导航，单手操作
▪️ 触摸友好


📱 使用方法

在线使用（推荐）

直接访问：https://codec2021.github.io/codecscope/

无需安装，打开浏览器就能用。

本地构建

如果你想自己构建：

▪️ 克隆仓库：git clone https://github.com/codec2021/codecscope.git
▪️ 构建 WASM：./build.sh
▪️ 本地预览：python3 -m http.server -d dist 8000
▪️ 浏览器打开 http://localhost:8000


🎬 典型使用场景

场景1：调试编码器输出
编码器输出有问题？拖入码流文件，直接看：
▪️ SPS 参数是否正确

场景2：分析码流结构

场景3：检查容器格式
MP4 文件打不开？MediaInfo 面板告诉你：
▪️ 轨道信息
▪️ 编码参数
▪️ 容器兼容性

场景4：HEIC 图片分析
想看看 iPhone 照片的编码结构？直接拖入 HEIC 文件：
▪️ Grid tile 结构
▪️ 每个 tile 的 NAL 单元
▪️ 语法树解析

❓ 常见问题

Q：支持哪些浏览器？
A：Chrome、Edge、Firefox 均可，推荐 Chrome。

Q：支持 RMVB/AVI 格式吗？
A：目前支持裸基本流（.h264/.h265/.h266）、MP4/MOV 容器、HEIC/HEIF 图片。

Q：视频播放不流畅？
A：视频播放基于 WebCodecs，需要浏览器支持。大文件建议使用逐帧步进。

Q：能导出分析结果吗？
A：目前暂不支持导出，但可以截图保存。
