CodecScope Help & About

About

  • Name: CodecScope — H.264 / H.265 / H.266 / AV1 Bitstream & Image Analyzer
  • Version: v1.0.0
  • Author: codec2021
  • Contact: github.com/codec2021

Usage

  • Open or drag-and-drop a .h264 / .h265 / .h266 / .mp4 / .mov / .webm / .ivf / .av1 / .obu file, or an image .heic / .avif / .jpg / .png / .gif / .webp.
  • NAL / OBU Unit List — click a unit to inspect its syntax tree, Hex bytes, and locate the frame on the timeline.
  • Frame Structure — timeline of slices colored by type (I=red, P=blue, B=green). Click a frame to preview; use Zoom +/- to resize, ⏮/⏭ to step frame by frame.
  • Syntax / Preview / Hex tabs — switch between parsed element tree, decoded video preview, and raw bytes.
  • Play — play decoded frames (rate follows the bitstream FPS when available), with progress highlight on the timeline.
  • MediaInfo tab — container-level metadata (format, duration, bitrate, tracks).
  • Splitters — drag the divider bars to resize columns / rows.

Supported

  • Video codecs: H.264 (AVC), H.265 (HEVC), H.266 (VVC), AV1
  • Containers: MP4 / M4V / MOV / WebM / IVF (auto-demux)
  • Images: HEIC / HEIF, AVIF, JPEG (EXIF), PNG, GIF, WebP, BMP
  • Video decode: WebCodecs (H.264/H.265) + vvdec WASM (H.266) + dav1d WASM (AV1)
  • Image decode: libheif WASM (HEIC) + dav1d WASM (AVIF) + browser-native (JPEG/PNG/…)
